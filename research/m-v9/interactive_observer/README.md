# 具体人物交互研究 v0

一个固定人物，一个Godot世界。Python只解析文本和托管有界推进。使用[启动说明](START_WINDOWS.md)；知识、权限、时钟与拒绝策略见[交互契约](INTERACTION_CONTRACT.md)。

默认文本入口不调用测试、回归或源码核验。退出审计仅在显式指定`--diagnostic`时加载；旧测试与历史交付保留原位，不作为运行或开发前置。默认会话也不积累旧Observation诊断记录。

军官命令送达受理与实际执行分开。目标状态来自已收报告；未收到就是未知。个人伤病为原连续能力份额，健康0仅表示失能。A系列入口增加真实成员调整与驻守目标粗化，语法见[当前接口](../attachment_continuity/README.md)。任意结构迁移、个人叶粗化、完整军职、生命周期、海空与正式接入仍未实现。
