# 预登记验收（M0，运行新增场景之前冻结）

所有输入是合成实验属性，未历史校准。旧断言/匹配器/生产路径保持。
基线必须在当前 Linux、固定引擎实际运行；旧 Windows 数字不计本轮证据。
官方PowerShell无法运行时仅称等价步骤；保留原fatal正则与退出码/完整尾日志。
经济golden只有冻结基线独立复现的相同失败可分类BASELINE_KNOWN_FAILURE；
其余失败、同平台结果改变及不明来源修改阻塞依赖阶段。

| 门 | 预登记输入/独立依据 | 通过条件 |
|---|---|---|
| M0 | 冻结Task8，Tasks1–8/五回归/统一/audit，双进程hash | 当前环境原始断言通过，基线已知失败独立记录；保护范围无变化 |

| M1 接触 | 局部物理距离与独立观察/火力许可；河/墙反例 | 相邻可合法接触；仅换cell ID无变化；通行和射击互不代替 |

| M3 长run | 100cell/400leaf、10–20活跃cell、1–2详细关注，24h，seed71/109 | 唯一表示/库存/权限/时间；不能400leaf全展开；查询无追账；局部变化不扩散99cell |
| M3 存储 | live/pending/身份/知识/诊断分类 | 诊断上限4096条或流式；总监测静态内存≤512MiB及pending≤100000，超限容量背压/停止；历史增长明报 |
| M4 | 冻结代码，完整原回归/新增测试/等价统一/audit | 无新增失败，最差case/seed/命令/退出码/版本齐全；范围audit；一Draft PR |

数值依据：纯移动参考无战斗/疲劳时绝对误差1e-8 km/s；资源和结构账用既有
浮点守恒尺度1e-6（重复/负/NaN拒绝不靠容差）。新空间不匹配旧一轴hash。
旧路径以当前Linux M0 hash为严格同平台参考。
跨LOD采用旧20%资源（尺度floor1）、0.20km移动、任务/控制趋势相符，时间
分区旧1%/2%界限不扩大。六固定seed沿用原测试seed并记录最差case/seed；
混合增加单侧聚合、局部物化和不同切换时点。1.99%不是新场景普适界限。
不同quota不得引入新积分边界，故要求精确因果物理等价。

工作口径分别记录：输入构建/索引；普通推进的area、segment、record、候选与
真实接触；聚合/物化/空间祖先更新；分页查询/序列化；事件heap比较/到期pop。
10000休眠area/30000squad不增加活跃核心计数；构建内存另报；1000未来只3到期
不得扫描997。稀疏候选不全配对；真实密集接触允许平方增长，不能删接触。
wall统计有限预热后至少5样本p50/p95/max，非用户机器帧率保证。

在途政策预先选择：关闭边将旅行者固定在该边当前弧长，不退款，不生成
伤亡；已知路线请求只有显式返程完成到端点才可转另一边（或等边重开）。
持久设施事实与局部几何缓存分离。route provider只收已收到报告/显式既定路。
补给ETA是独立外部到达，路线化物流未完成。铁路只引用availability/capacity。

每轮记缺口→可验证假设→最小改动→实际测试→改善/保留理由→下一步。
同失败两轮无改善先最小反例；约45分钟无可信修正判定BLOCKED/DEFERRED。
不得为达成LEVEL临时改本表标准；必要核心/权限/冻结断言变化停止。
